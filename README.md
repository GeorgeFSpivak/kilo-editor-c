# Kilo Editor C

Study project developed in C. The development follows the Build Your Own Text Editor tutorial, based on the Kilo editor:

- Tutorial: https://viewsourcecode.org/snaptoken/kilo/
- Step-by-step source code: https://github.com/snaptoken/kilo-src
- Original repository: https://github.com/antirez/kilo

Thanks to snaptoken for the tutorial and its clear explanations, and to Salvatore Sanfilippo for creating Kilo.

This repository is used to practice C programming, raw terminal mode, VT100 escape sequences, terminal I/O, file handling, dynamic memory management, and the internal structure of a text editor.
